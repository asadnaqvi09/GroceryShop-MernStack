# 🛍️ Grocery Shop FrontEnd
This repository contains fully functional Mern Stack Grocery-Shop Project (Bazaarly).
---

## 🚀 Features

### ✅ Frontend (Completed)
- Fully responsive UI (Desktop + Mobile + Tablet)
- Homepage & Products listing
- Cart & Checkout pages
- User authentication forms (Login/Register/Forgot-Password/Reset-Password/Verification-Code)
- Product details page
- Search Page

### ✅ Backend (Completed)
- Authentication Api's (Login,Register,Forgot-Password,Reset-Password,VerifyOTP,Resend-OTP)
- Review Api's (CRUD Operations)
- Product Api's (getAllProducts,getProductsByCategory,getProductById,searchProducts)
Note: We use seed Data to insert upto 20 Products in Our Database you can check folder seedData/seed.js file in Backend folder.We are not using Admin Panel we did not add CreateProduct,DeleteProduct,UpdateProduct Api's

## 📂 Project Status
- **Frontend:** ~100% Completed  
- **Backend:** ~100% Completed

## ⚡ How to Run Locally

```bash
# Clone this repository
git clone https://github.com/asadnaqvi09/Grocery-Shop-FrontEnd.git

# Navigate to the project folder
cd Grocery-Shop-FrontEnd

# Install dependencies (Frontend & Backend separately)
cd Frontend
npm install
npm run dev
